# Contributors

Docket is built by the people listed here. The list is regenerated at release time from git
history (`git shortlog -sne --no-merges`) and reconciled by hand; if you are missing from it,
open an issue titled "add me to CONTRIBUTORS" with your preferred name and link.

## Maintainer

- **The Docket maintainers** — see [`MAINTAINERS.md`](MAINTAINERS.md). One person until the
  project earns more; the governance document describes how that changes.

## Contributors

*None yet — the repository has not been published.* The first external contributor to get a
merged pull request will be listed here in the commit that merges it, along with what they
changed, because a contribution list that starts empty and fills honestly is more useful than
one that starts with a placeholder.
