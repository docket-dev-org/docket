conformance vectors, and holds the Format Steward role for the first year as described in

governance document removes founders' special rights deliberately, and the format-change
process binds this maintainer exactly as it binds everyone else.

**Emeritus:** none yet.

## What maintainers do here

- triage issues and pull requests (target: first response within a week; 72 hours for the
  *Legible* sponsorship tier and above, as promised in [`SPONSORS.md`](SPONSORS.md));
- cut releases: tag, CI build, signed `SHA256SUMS`, release notes from `CHANGELOG.md`;
- own the security response window described in [`SECURITY.md`](SECURITY.md);
- keep the specification and the vectors in step with the implementations — the one
  non-negotiable responsibility in this project.

## How to become one

Sustained participation described in [`GOVERNANCE.md`](GOVERNANCE.md#becoming-a-maintainer).
The short version: reviews that catch real problems, fixes for issues you did not create, and
a verifier or integration you keep alive rather than merely contribute once.
